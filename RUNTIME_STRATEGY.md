# PRFKT Runtime Strategy

## OpenClaw

Persistent workspace, employee-like interface, tools, memory, channels, schedules, devices. Primary CLAW runtime.

## LangGraph

Stateful/durable workflows, checkpoints, pause/resume, approvals, retries. Primary FLOW engine. First acceptance project: PRFKT_FLOW_01.

## CrewAI

Specialist teams customers understand. Primary CREW framework for marketing, research, recruiting, and collaborative work. Critical state changes still require deterministic validation.

## PydanticAI

Typed tools and structured outputs. Primary STRICT framework; also useful inside FLOW/CLAW for finance, inventory, manufacturing, CRM, and provisioning schemas.

## ZeroClaw

Lightweight runtime candidate for EDGE: cheap VPS, Raspberry Pi, kiosks, appliances, local systems. Do not market upstream performance claims until PRFKT reproduces them.

## NemoClaw / enterprise candidates

Treat as candidates inside SECURE. PRFKT SECURE is a runtime-independent acceptance standard.

## TrustClaw

Use ComposioHQ TrustClaw as an architectural reference for Next.js, OAuth integrations, sandboxed execution, memory, schedules, and action logs. Avoid unnecessary hard dependency unless intentionally chosen.

## OpenCode

Development worker/harness, not universal customer-facing intelligence.

## Ollama

First-class local route for private, routine, cost-sensitive, and local workloads.
